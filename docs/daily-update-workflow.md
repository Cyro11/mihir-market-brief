# Daily Update Workflow

Use `index.html` as the canonical newsletter template.

## Daily Process

1. Gather free-source reporting:
   - Reuters, AP, CNBC, Yahoo Finance, MarketWatch
   - FRED, BLS, BEA, Treasury, Federal Reserve
   - SEC filings, company releases, investor presentations, earnings transcripts
2. Validate importance:
   - check whether a similar story or theme appears in WSJ, FT, or NYT where accessible
   - do not copy paywalled text
3. Update the issue:
   - top market-moving headlines
   - rates / Fed / macro interpretation
   - deal watch
   - sector or company lens
   - charts and visual callouts
4. Preserve the design:
   - keep the current newspaper/research layout
   - avoid converting it into a generic dashboard
   - update content inside the existing visual system first
5. Archive the issue:
   - copy the completed daily issue to `issues/YYYY-MM-DD.html`
   - keep `issues/latest.html` and `index.html` in sync

## Editorial Rule

The newsletter should be useful for banking judgment: valuation, financing, deal activity, sector read-throughs, and second-order effects.
